BarcodeSuite — User Guide

A graphical suite of utilities for working with FASTQ and FASTA files in DNA barcoding workflows (compatible with ONTbarcoder / Nanopore, BOLD and GenBank outputs).

Graphical interface (PyQt5) Drag & drop Windows / cross-platform

What does this program do? barcodeSuite.py opens a window with six tabs, each an independent tool:

FASTQ Inspector
Full descriptive report of a FASTQ file (quality, length, GC, plots).
FASTA Tools
7 operations on FASTA: unique, identical, grep, filtering, append info, reformat, sort.
FASTA Compare
Compares multiFASTA files from different runs sample by sample (identical / compatible / different).
BLAST NCBI
Online BLAST search against NCBI databases with taxonomy.
GenBank Batch
Batch search in GenBank with up to two crossed criteria: counts, metadata and FASTA.
BOLD Formatter
Reformats the BOLD "Barcode ID" Excel workbook to the style of the BLAST report.

Requirements & installation

Python dependencies

The program requires Python 3 and the following libraries:

pip install PyQt5 edlib xlsxwriter openpyxl
  • PyQt5 — graphical interface.
  • edlib — fast sequence alignment (used in the comparison).
  • xlsxwriter / openpyxl — reading and writing Excel files (.xlsx).
Automatic installation When you run python barcodeSuite.py from source, the app checks these four dependencies (and pip itself) at startup and automatically installs any that are missing. This does not apply to the packaged version (.exe), which already bundles everything.

Running the program

# From the project folder
python barcodeSuite.py
Icon and title If an icon.ico file exists next to the script, it is used as the window and taskbar icon. On Windows the app appears as "BarcodeSuite".
Packaged version (.exe) The code is prepared to run frozen with PyInstaller (multiprocessing.freeze_support()), so it can also be distributed as an executable without needing Python installed.

General interface concepts

All tabs share the same working logic:

🖱️ Drop zone
Drag files onto the indicated area, or use the Browse… button to locate them. One or several files are accepted depending on the tool.
⚙️ Options
Each operation shows its own parameters. They appear and hide depending on what you select.
▶ Run
The main button (Run →, Start comparison →, Format →) launches the process in the background; a progress bar shows the advance.
📄 Log
A text panel shows the detail of each operation and the files generated.
📂 Open folder
When finished, the Open folder 📂 button opens the folder with the results.
🗑️ Clear
Resets the tab and clears the loaded files.
Accepted formats FASTA: .fa, .fas, .fasta, .fna (also gzip-compressed .gz). FASTQ: .fastq, .fastq.gz. Excel: .xlsx.

1 · FASTQ Inspector

Full descriptive report of a FASTQ file.

Drag one FASTQ file (.fastq or .fastq.gz) to obtain a statistical analysis of every read. Processing is parallel (multiprocessing) for large files.

  • Distribution of the mean Q-score per read.
  • Distribution of %GC per read.
  • Scatter: length vs. mean Q-score.
Note All reads are analyzed for the statistics; only the scatter plot uses a random sample of 10,000 points to stay responsive.

How to use it

  1. Drag the FASTQ file onto the tab's drop zone.
  2. Wait for the analysis to finish (progress bar).
  3. Review the statistics cards and the four plots.

2 · FASTA Tools

Seven operations on one or more FASTA files.

Drag one or more FASTA files and choose the operation. Each operation generates its output file(s) in the same folder as the input files.

Merge files The "Merge files before processing" checkbox controls the mode:
  • Checked: all files are concatenated into a single set and the operation is applied to the combined set → a single output.
  • Unchecked: each file is processed separately → one output per file.

2.1 · Extract unique sequences

Extracts the non-repeated sequences. Output: <name>_unique.fasta

2.2 · Extract identical sequences (duplicates)

Extracts the sequences that appear more than once. Generates two files:

  • <name>_identical.fasta — the duplicated sequences.
  • <name>_duplicate_groups.xlsx — IDs grouped by shared sequence.
    • IDs sheet: list of IDs per group.
    • Groups sheet: group number, number of IDs and the sequence.

2.3 · Extract sequences by pattern (grep)

Filters by a match in the FASTA header. Output: <name>_grep.fasta

  • Pattern: type the search text directly, or
  • Load patterns from file: load a .txt with one pattern per line (empty lines are ignored). Each pattern is compared against the full header.
  • Use regex: interpret each pattern as a regular expression.

2.4 · Filter by header fields

Splits each header by a separator and filters by field position. Output: <name>_filtered.fasta

  • Field separator: | (pipe), ; (semicolon) or a custom one.
  • Preview: shows the fields of the first loaded sequence to help locate positions.
  • Criteria (several can be added; they are applied with AND logic — all must be met):
    • Numeric operators: >= <= > < = !=
    • Text operators: = != contains not contains

2.5 · Append information to headers from .xlsx

Adds fields to each header from an Excel file. Output: <name>_append.fasta

Excel format Column 1 = sequence ID (same as the FASTA header, without >); columns 2+ = fields to append. Values are normalized: leading/trailing spaces are removed, spaces/periods/commas are converted to _ and accents are stripped.

Separator used to join the appended fields: | or ;.

2.6 · Reformat sequence lines

  • Multiline → single line (linearize / unwrap): joins the sequence into a single line.
  • Single line → multiline (wrap): breaks the sequence every N nucleotides (default 80, configurable from 10 to 10,000).

Output: <name>_linearized.fasta / <name>_wrapped.fasta

2.7 · Sort sequences

Sorts the sequences by the header or by header fields. Output: <name>_sorted.fasta

  • Field separator: none (full header), |, ; or custom.
  • Sort levels: several can be added (multi-key sort, applied top to bottom), each with a field and a direction (ascending/descending).

3 · FASTA Compare

Compares multiFASTA files from different runs, sample by sample.

Use it to contrast the barcodes obtained from the same sample across several runs. The sample ID is extracted from the FASTA header and used to pair sequences between files.

Sample ID extraction

Positional mode (simple)

  • ID delimiter: character (or text) that separates the ID from the rest of the header (_ typical of ONT, | for BOLD/GenBank). Multi-character delimiters are supported.
  • before occurrence: which occurrence of the delimiter marks the end of the ID (1st, 2nd, …). E.g. with _ and "1st" it takes everything before the first _.
  • any of these: treats the delimiter field as a set of characters and cuts at the first one that appears. Useful when the same ID is followed by different separators in each file (e.g. _- makes BIOUG00045_all.fa and BIOUG00045-all.fa both yield BIOUG00045).
  • A preview shows the resulting ID live over an example header.

Advanced mode (Regex)

For files with different header conventions:

  • Regex (one per line): tried in order until one matches. If it has a capture group, group 1 is used; otherwise the full match. E.g. ^(\S+?)_all\.fa , ^([^|]+)\|
  • Normalize ID:
    • lowercase — converts the ID to lowercase.
    • strip leading zeros — removes leading zeros within numbers (BIOUG00045 → BIOUG45).
    • strip (regex) — removes from the ID whatever matches the regex (useful for stripping run/replicate suffixes, e.g. _S\d+$).
Purpose of normalization To make the same sample "collide" (match) across files with different naming conventions.

Comparison modes

  • Compare sets with each other — compares all sets against each other and classifies each sample as identical / IUPAC-compatible / different / unique.
  • Compare against reference — one file acts as reference and the rest are compared against it.

Output files

When starting, the destination folder is requested. The following are generated:

FileContent
summary.xlsxSummary table colored by the status of each sample.
best_barcodes.faThe best sequence chosen per sample.
identical.faSamples with an identical sequence across files.
compatible_iupac.faSamples compatible according to IUPAC codes.
different.faSamples with different sequences.
only_in_reference.fa / without_reference.faReference mode only.
unique_<file>.faSamples present in a single file (one per file).

Buttons after finishing: Show table ↗ (view the table in the app), Open folder 📂 and Open Excel 📊.

4 · BLAST NCBI Search

Online BLAST search of your sequences against NCBI databases.

Drag one or more FASTA files. Results can include the organism and its taxonomic classification from NCBI Taxonomy.

⚠ An NCBI API key is required You must register a personal (free) key at ncbi.nlm.nih.gov/account and paste it in the NCBI API Key field. The key is saved automatically for future sessions.

Parameters

OptionDescription
Databasecore_nt, nt, refseq_rna, 16S_ribosomal_RNA
Programblastn + MEGABLAST (recommended), blastn, or megablast
Hits per sequenceNumber of results per sequence (1–100, default 5)
Sequences per batchSequences per batch (default 50; ≤50 recommended)
Taxonomy lookupRetrieves organism + taxonomic classification (enabled by default)
⚠ NCBI usage policy NCBI monitors and penalizes excessive use of its servers. Sending too many requests in a short time can lead to temporary or permanent IP blocking or API key suspension. Keep batches at ≤ 50 sequences and avoid multiple or very long simultaneous sessions.

Output

A results table is generated in .tsv and .xlsx with the hits per sequence (accession, organism, taxonomy, % identity, etc.). The live log shows the progress per batch: info, BLAST, organism, taxonomy, progress and result.

How to use it

  1. Paste your NCBI API key (only the first time).
  2. Choose database, program, number of hits and batch size.
  3. Drag your FASTA files and press run. You can stop with Stop.
  4. When finished, open the folder with the results table.

5 · GenBank Batch Search

Batch search in GenBank (nucleotide) with up to two crossed criteria.

Replaces the old bash scripts GB-retrieve-by-region and GB-retrieve-by-species (based on NCBI EDirect, which does not run natively on Windows) with a graphical interface: define a list of terms for Criterion 1 (e.g. species), optionally crossed with a Criterion 2 (e.g. country/region or gene), and obtain record counts, metadata and FASTA sequences directly from the NCBI API (E-utilities), without depending on external utilities.

NCBI API key (optional)

Unlike BLAST, the key is not mandatory here: without it NCBI limits to ~3 requests/sec; with it, up to ~10/sec. It is saved in the same file used by the BLAST tab (_profiles/blast_config.json), so if you already configured it there you do not need to paste it again.

Criterion 1 and Criterion 2

  • Field: the NCBI search tag — Organism, Country, Gene, Title, All Fields, Accession, Author, Journal.
  • Term list: type or paste one term per line, or drag a .txt/.csv file onto the field (it highlights when dragging a valid file). The "N terms" counter updates live. The ✕ Clear list button empties only that list.
  • Criterion 2 (optional): enabled with the "Add second criterion" checkbox. With a single value, it acts as a fixed filter applied to every term of Criterion 1 (equivalent to the region=colombia of the old scripts). With several values, they are crossed with each term of Criterion 1 (Cartesian product: each combination is an independent query).

Options

OptionDescription
Records per query (cap)Maximum records to download per query (1–10,000, default 500). Does not limit the count shown — only how many records are downloaded for metadata/FASTA.
Record counts (CSV)Always active: a record count per term/combination.
Metadata (XLSX)Table with accession, organism, marker/gene, definition, length, molecule type, division, country, isolate, specimen voucher, collection date, coordinates, taxon ID, creation/update dates and taxonomy.
Sequences (FASTA)Sequences with header accession|organism|marker|term1|term2.
⚠ NCBI usage policy A high cap combined with long term lists can generate many requests. Keep batches reasonable and avoid simultaneous or very prolonged sessions.

Customize summary report

Optional section that adds extra columns to the counts table: for each term, how many distinct values were found in a field and/or which they are. Available columns: Marker/Gene, Moltype, Division and Country.

  • Count: number of distinct values found.
  • List values: lists the values found (ordered by frequency).
  • With counts: next to each value in the list, how many times it appeared — e.g. Colombia (12).
  • Limit list to N values: trims the list shown in the cell (the total count is still exact, with a "… +N more" note).
Note Customizing the summary requires downloading each record from NCBI (subject to the cap above), even if you do not save metadata or FASTA — it is the only way to compute the distinct values per term, since GenBank is a remote API and does not offer server-side aggregations the way the local BOLD database does.

Molecular marker (Marker/Gene)

GenBank has no dedicated field for a molecular marker. It is taken from the first feature of the record (gene, CDS, rRNA, tRNA…) other than source: its /gene qualifier (short name, e.g. "COX1") or, if it does not exist, /product (descriptive text, e.g. "large subunit ribosomal RNA").

Inconsistent nomenclature Since it is not standardized, the same gene can appear written in different ways across records (COI / COX1 / CO1 / cox1…). If you are going to use "Marker/Gene" for exact counts, it is advisable to review/normalize those values afterward.

Output files

When you press Search GenBank →, a destination folder is requested (automatic or manual). The following are generated:

FileContent
genbank_batch_counts_<date>.csvOne row per term/combination with the record count (+ customized summary columns, if enabled).
genbank_batch_metadata_<date>.xlsxCompiled metadata from all terms (if "Metadata" is checked).
genbank_batch_sequences_<date>.fastaCompiled sequences from all terms (if "Sequences" is checked).
individual_results/<term>/One subfolder per term (or per term1+term2 combination) with its own metadata_<term>.xlsx and sequences_<term>.fasta.

How to use it

  1. (Optional) Paste your NCBI API key — it speeds up the searches.
  2. Choose the Criterion 1 field and type, paste or drag your list of terms.
  3. (Optional) Enable Criterion 2 with a fixed value or a list to cross.
  4. Adjust the record cap and check which outputs you want (metadata, FASTA, customized summary).
  5. Press Search GenBank →. The progress bar advances per query and also within large downloads of a single query. You can stop with Stop.
  6. When finished, open the folder with Open folder 📂.

6 · BOLD Formatter

Restyles the BOLD "Barcode ID" Excel workbook to the BLAST report format.

Takes a .xlsx file exported from BOLD and reformats it to match the BLAST results workbook: a "Hit rank" column per group, top-N hits per Query ID, colors per group, alternating fills, frozen header and filters.

Expected input format BOLD "Barcode ID" workbook: one title row, one header row with columns "Query ID" and "ID%", and then the hit rows grouped by Query ID.

Options

  • Hits to keep per Query ID: how many hits to keep per query (1–999, default 5).
  • Keep all hits: keeps all hits and ignores the limit above.

Output: <name>_formatted.xlsx

How to use it

  1. Drag or select the .xlsx exported from BOLD.
  2. Set how many hits to keep (or check "Keep all hits").
  3. Press Format → and open the formatted file with Open folder 📂.

Tips & troubleshooting

The app does not open
It should install whatever is missing (PyQt5, edlib, xlsxwriter, openpyxl) on startup when run from source. If it fails, install them manually and check the error message in the console.
BLAST fails or hangs
Almost always a missing/incorrect API key or a block from excessive NCBI use. Reduce the batch size and wait.
The comparison does not pair samples
Adjust the delimiter and occurrence, use "any of these", or switch to Regex mode + normalization to unify naming conventions.
"Append" does not find IDs
Column 1 of the Excel file must match the FASTA header (without >). Remember the value normalization.
Very large FASTQ
The analysis uses multiprocessing; the scatter plot samples 10,000 points, but the statistics cover all reads.
Where do the outputs go?
In FASTA Tools and BOLD, next to the input files. In Compare and GenBank Batch, in the folder you choose when starting. Always use Open folder 📂.
GenBank Batch is very slow
Without an NCBI API key the limit is ~3 requests/sec. Paste a (free) key to go up to ~10/sec, and avoid very high record caps with long lists.
